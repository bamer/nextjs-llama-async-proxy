# Administrative Agent Coordination Protocol

## Mission Statement
Coordinate specialized administrative agents to deliver comprehensive, validated, and innovative solutions for complex administrative challenges.

## Coordination Architecture

### Orchestrator Role (Multi-Agent Coordinator)
- **Primary**: big-pickle model
- **Responsibilities**:
  - Task decomposition and assignment
  - Agent coordination and synchronization
  - Results aggregation and validation
  - Quality assurance and delivery
  - Cross-agent learning capture

### Agent Activation Protocol

#### 1. Task Reception
```
User Request → Orchestrator Analysis → Agent Assignment
```

#### 2. Agent Selection Matrix
| Task Complexity | Primary Agents | Secondary Support |
|----------------|----------------|------------------|
| Simple Analysis | Researcher | - |
| System Design | Architect | Researcher |
| Problem Solving | Creative | Architect |
| Validation | Skeptic | Researcher |
| Complex Multi-stage | All 4 | Coordinated sequence |

#### 3. Parallel Execution Rules
- **Independent tasks**: Execute in parallel
- **Sequential dependencies**: Stage-based handoffs
- **Cross-functional**: Collaborative workspaces

### Communication Protocols

#### Agent-to-Agent Communication
```
[SENDER] → [RECEIVER]: [MESSAGE_TYPE]
- REQUEST: Data or analysis needed
- RESPONSE: Findings or deliverable
- COLLABORATE: Joint work required
- VALIDATE: Review needed
```

#### Status Updates
```
Agent → Orchestrator: STATUS_UPDATE
- IN_PROGRESS: Working on task
- BLOCKED: Requires input
- COMPLETE: Deliverable ready
- ISSUE: Problem encountered
```
