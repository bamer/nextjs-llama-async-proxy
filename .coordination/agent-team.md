## Coordination Protocols

### Communication Flow
1. **Orchestrator** receives task request
2. **Task decomposition** into specialized components
3. **Agent assignment** based on expertise requirements
4. **Parallel execution** where possible
5. **Cross-agent collaboration** for complex tasks
6. **Results aggregation** and final validation

### Decision Matrix
| Task Type | Primary Agent | Secondary Support |
|-----------|---------------|-------------------|
| Project Auditing | Researcher | Skeptic |
| System Design | Architect | Researcher |
| Innovation | Creative | Architect |
| QA Testing | Skeptic | Researcher |
| Performance Analysis | Researcher | Architect |
| Security Assessment | Skeptic | Creative |

### Handoff Protocols
- **Research → Architect**: Analysis findings inform design
- **Architect → Creative**: Design constraints guide innovation
- **Creative → Skeptic**: Solutions require validation
- **Skeptic → Research**: Issues require investigation
